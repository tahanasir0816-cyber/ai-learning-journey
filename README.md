# ai-learning-journey
My 12-week AI learning journey for HR analytics
## Week 1 - Day 1: How LLMs work (3 Nov 2026)
LLMs don't search like Google. They predict the next word based on patterns learned from huge amounts of text, so they generate answers rather than look them up.
Clear context gives better output. A vague prompt like "write a probation letter" gets a generic answer, but adding role, company type, employee details and tone gets a ready-to-use letter.
AI can hallucinate, which means it can sound confident and still be wrong. Facts like UAE Labour Law articles, gratuity rules and dates should always be verified from official sources such as MOHRE.
